
# Sloopy! iOS Build Guide

This repository contains the Sloopy! PWA and its Capacitor 8.6.2 iOS wrapper configuration.

## Requirements

- Node.js 22 or newer
- npm
- GitHub Actions enabled for this repository

For iOS compilation, the workflow uses a GitHub-hosted macOS 26 runner with Xcode 26 or newer.

## Install and Check Dependencies

Run these commands from the repository root:

```bash
npm ci
npm run check
```

The `package-lock.json` file ensures reproducible npm dependency installation.

## iOS Project Generation

The iOS project is generated by the GitHub Actions workflow using Capacitor and Swift Package Manager:

```bash
npx cap add ios --packagemanager SPM
npx cap sync ios
```

The generated `ios/` directory is not committed to this repository. It is generated during the CI build.

## GitHub Actions Workflows

This repository contains two workflows:

### 1. Sloopy CI

Workflow name: `Sloopy CI`

Runs automatically for:
- Pull requests targeting `main`
- Pushes to `main`

It installs dependencies, runs `npm run check`, and performs a non-blocking npm security audit.

### 2. Sloopy iOS Unsigned Build

Workflow name: `Sloopy iOS Unsigned Build`

Runs automatically for qualifying pull requests targeting `main` when relevant project files change.

It can also be started manually from the GitHub Actions tab after the workflow is available on the default branch:

1. Open the repository on GitHub.
2. Select **Actions**.
3. Select **Sloopy iOS Unsigned Build**.
4. Click **Run workflow**.
5. Select the desired branch and start the workflow.

The workflow:
- Installs npm dependencies.
- Generates and synchronizes the Capacitor iOS project.
- Resolves Swift Package Manager dependencies.
- Builds the iOS application with Xcode without code signing.
- Packages the application into an IPA artifact.

## Download the Build Artifact

After a successful workflow run:

1. Open the completed workflow run.
2. Find the **Artifacts** section.
3. Download `Sloopy-unsigned-IPA`.

The artifact is configured to be retained for 7 days.

A successful workflow run is required before considering the IPA build verified. The workflow configuration alone does not prove that an IPA has been built successfully.

## Important Signing Limitations

The generated IPA is unsigned.

It is a build artifact, not a signed iOS distribution that can normally be installed on a standard iPhone.

A normal iOS installation requires an app signature and provisioning accepted by Apple.

This repository does not contain signing certificates, provisioning profiles, Apple Account passwords, or signing credentials.

Never upload private signing credentials or Apple Account passwords to this repository.

## App Details

- Display name: Sloopy!
- Bundle identifier: `com.sloopy.daily`
- Web assets: `www/`
- Capacitor version: `8.6.2`
- Minimum Node.js version: `22`

## Known Limitations

- Weather, YouTube live streams, and remote app shortcuts require internet access.
- Camera embedding depends on each YouTube channel's embed permissions.
- Notes, profile, theme, accent, stamps, selected camera, and routine state are stored locally.
- No cross-device synchronization is configured.
- The application does not read notifications from other iPhone apps or block them.
